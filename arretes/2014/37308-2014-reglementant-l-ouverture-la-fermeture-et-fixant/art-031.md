# Article 31

Les locaux doivent être composés d’au moins cinq salles dont une salle de consultation, une salle de soins, une salle d’attente, une salle de surveillance de malade, et d’une Pharmacie dont les dimensions sont respectivement de :

- salle de consultation : 4m x 3m x 2,5m;

- salle de soins : 3m x 3m x 2,5m;

- salle d’attente : abritant au moins 10 personnes;

- salle de surveillance de malade : 3m x 3m x 2,5m;

- salle Pharmacie : 2m x 3m x 2,5m.
