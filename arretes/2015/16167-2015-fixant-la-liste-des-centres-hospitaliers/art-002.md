# Article 2

Sont reconnus Centres Hospitaliers Universitairesà Madagascar :

Pour Antananarivo :

Le Centre Hospitalier Universitaire Joseph Ravoahangy Andrianavalona (CHU JRA);

Le Centre Hospitalier Universitaire de Soins et de Santé Publique Analakely (CHU SSPA);

Le Centre Hospitalier Universitaire Joseph Raseta Befelatanana (CHU JRB);

Le Centre Hospitalier Universitaire Mère Enfant Tsaralalana (CHU MET);

Le Centre Hospitalier Universitaire de Gynécologie et Obstétrique Befelatanana (CHU GOB);

Le Centre Hospitalier Universitaire Mère Enfant Ambohimiandra (CHU MEA);

Le Centre Hospitalier Universitaire Fenoarivo (CHU F);

Le Centre Hospitalier Universitaire de Santé Mentale Anjanamasina (CHU SMA);

Le Centre Hospitalier Universitaire de Stomatologie et de Chirurgie Maxillo-Faciale (CHU STOCMF);

Le Centre Hospitalier Universitaire d`Appareillage de Madagascar (CHU AM);

Le Centre Hospitalier Universitaire Andohatapenaka(CHU Andohatapenaka);

Le Centre Hospitalier Universitaire Anosiala (CHU Anosiala).

Pour Antsiranana :

Le Centre Hospitalier Universitaire Place Kabary (CHU Place Kabary) ;

Le Centre Hospitalier Universitaire Tanambao I (CHU Tanambao I) ;

Pour Mahajanga :

Le Centre Hospitalier Universitaire Professeur Zafison Gabriel Androva(CHU P.ZA. GA);

Le Centre Hospitalier Universitaire Mahavoky Atsimo (CHU Mahavoky Atsimo) ;

Pour Toamasina :

Le Centre Hospitalier Universitaire Analakininina (CHU Analakininina) ;

Le Centre Hospitalier Universitaire Morafeno (CHU Morafeno) ;

Pour Fianarantsoa :

Le Centre Hospitalier Universitaire Tambohobe (CHU Tambohobe) ;

Le Centre Hospitalier Universitaire Andrainjato (CHU Andrainjato) ;

Pour Toliara :

Le Centre Hospitalier Universitaire Antanambao (CHU Antanambao) ;

Le Centre Hospitalier Universitaire Mitsinjo Betanimena (CHU Mitsinjo Betanimena ).
