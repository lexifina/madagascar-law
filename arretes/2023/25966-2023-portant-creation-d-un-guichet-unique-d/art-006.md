# Article 6

Toutes les mesures légales ou réglementaires s'imposant à l'exportateur, notamment celles sur l'obligation de rapatriement des devises, sur les documents requis conformément aux conditions prévues par le Code Minier, le Code des Douanes, le Code des Changes, le Code des Impôts et le Code des procédures fiscales ainsi que par les textes pris pour leur application, demeurent applicables.
