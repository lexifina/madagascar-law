# Article 5

Dans le cadre de ces activités, les obligations de service annuelles sont fixées comme suit :

Type 1 :

125 heures d’ED annuelles pour les Enseignants-Chercheurs et 50 heures d’ED pour les Chercheurs-Enseignants, Type 2 :

75 heures d’ED annuelles pour les Enseignants-Chercheurs et 08 heures par jour (jours ouvrables) pour les Chercheurs-Enseignants, Type 3 :

Les rubriques de ce type d’obligation ne peuvent pas faire l’objet d’une déclaration d’heures d’activités accomplies.
