# Article 8

Le CNOOS est composé de dix-huit (18) membres, dont douze (12) membres titulaires, et six (06) membres suppléants.

Les membres titulaires sont constitués : d’un (01 ) Président ; de deux (02) Vice Présidents ; d’un (01) Secrétaire Général ; d’un (01) Secrétaire Général Adjoint ; d’un (01 ) Trésorier Administratif ; d’un (01 ) Trésorier Financier ; de cinq (5) Conseillers.

Le CNOOS dispose d’un Secrétariat Administratif.
