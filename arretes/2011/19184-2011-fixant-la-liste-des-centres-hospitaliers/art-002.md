# Article 2

Sont reconnus comme Centres Hospitaliers Universitaires à Madagascar :

I. Le Centre Hospitalier Universitaire d'Antananarivo regroupant :

Hospitalier Universitaire Joseph Ravoahangy Andrianavalona (H.U.J.R.A) ;

Etablissement Universitaire de Soins et de Santé Publique d'Analakely (E.U.S.S.P.A) ;

Hospitalier Universitaire Joseph Raseta de Befelatanana (H.U.J.R.B) ;

Hospitalier Universitaire Mère Enfant de Tsaralalana (H.U.M.E.T) ;

Hospitalier Universitaire de Gynécologie et Obstétrique de Befelatanana (H.U.G.O.B) ;

Hospitalier Universitaire Mère Enfant d'Ambohimiandra (H.U.M.E.A) ;

Hospitalier Universitaire de Fenoarivo (H.U.F) ;

Hospitalier Universitaire de Santé Mentale d'Anjanamasina (H.U.S.M.A) ;

Centre de Stomatologie de Befelatanana (STOMATO Befelatanana) ;

Centre d'Appareillage de Madagascar (C.A.M).

II. Le Centre Hospitalier Universitaire de Mahajanga;

III. Le Centre Hospitalier Universitaire de Fianarantsoa;

IV. Le Centre Hospitalier Universitaire de Toamasina;

V. Le Centre Hospitalier Universitaire d'Antsiranana;

VI. Le Centre Hospitalier Universitaire de Toliary.
