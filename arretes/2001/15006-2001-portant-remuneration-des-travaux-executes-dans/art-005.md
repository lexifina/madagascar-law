# Article 5

Les indemnités pour les travaux cités ci-dessus sont payées par les usagers demandeurs.

Ces indemnités sont liquidées selon le tarif unique de dix mille francs (10 000 FMG).

Le tarif ci-dessus est majoré de 50% pour les travaux exécutés pendant les jours ouvrables à partir de vingt heures (8 h du soir) jusqu’à six heures (6 h) du matin le lendemain.

Il est doublé pour les travaux exécutés pendant les jours fériés.
