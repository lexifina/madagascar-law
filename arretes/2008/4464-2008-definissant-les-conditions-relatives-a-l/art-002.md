# Article 2

Il est institué trois types d'espaces aériens particuliers pour les besoins d'opérations aériennes à l'intérieur du territoire national et des eaux territoriales :

les zones dangereuses : espaces aériens de dimensions définies, dans les limites desquels des activités dangereuses pour le vol des aéronefs peuvent se dérouler pendant des périodes spécifiées.

les zones réglementées : espaces aériens de dimensions définies, dans les limites desquels le vol des aéronefs est subordonné à certaines conditions spécifiées.

les zones interdites : espaces aériens de dimensions définies, dans les limites desquels le vol des aéronefs est interdit.
