# Article premier

Le code de conduite est un ensemble de règles et de standards de comportements dans un environnement particulier. Il définit ce qu’il faut faire et ne pas faire. Il s’appuie sui des valeurs éthiques qui se réfèrent aux principes moraux, base du comportement de l’individu. A la différence du code d ’éthique, il est obligatoire et sanctionne les contrevenants.

Vu la loi n° 2004-030 du 9 septem bre 2004 sur la lutte contre la corruption, Section II Champ d ’application
