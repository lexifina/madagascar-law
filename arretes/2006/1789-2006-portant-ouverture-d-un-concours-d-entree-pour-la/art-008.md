# Article 8

a) Les centres de correction des épreuves sont :

- L'INFP Mahamasina pour le faritany d'Antananarivo ;

- La DIRESEB d'Antsiranana pour le faritany d'Antsiranana ;

- Le CRINFP de Mahazengy pour le faritany de Fianarantsoa ;

- Le CRINFP de Mahabibo pour le faritany de Mahajanga ;

- Le CRINFP EPP Augagneur pour le faritany de Toamasina ;

- Le CRINFP EN.1 Toliara pour le faritany de Toliara ;

b) A la fin des corrections, les dossiers et registres des notes des candidats seront acheminé vers l'INFP - Mahamasina, où aura lieu la délibération finale pour l'admission définitive des candidats suivant les choix de CISCO d'affectation des candidats en cas de recrutement
