# Article 2

Le nombre total de places ouvertes pour le présent recrutement est fixé à VINGT CINQ (25) pour le parcours « Administration hospitalière ».

- Vingt (20) places mises au concours sont reparties comme suit:

- deux (02) pour les candidats du CENHOSOA ;

- dix huit (18) pour les autres candidats de nationalité Malagasy ;

- Cinq (05) places sur sélection de dossier dont :

trois (03) pour les candidats des institutions ayant contracté une convention avec l’INSPC;

deux (02) pour les candidats de nationalité étrangère;
