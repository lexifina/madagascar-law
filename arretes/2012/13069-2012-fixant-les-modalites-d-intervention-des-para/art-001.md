# Article premier

Le présent arrêté détermine les modalités d’intervention des Para-Professionnels Vétérinaires dans leur profession.

Les para-professionnels vétérinaires (PPV) sont constitués par les agents cités ci-après :

Réalisateurs et Réalisateurs Adjoints (Option élevage);

Techniciens Supérieurs (Option élevage);

Adjoints Techniques d’Elevage;

Assistants d’Elevage;

Employés Techniques d’Elevage;
