# Article 14

Les droits de tirage relatifs aux reproductions de plan dont les papiers sont fournis par les intéressés sont fixés comme suit :

mille Ariary (Ar.1.000) pour le format 720mm x 1020mm ;

mille Ariary (Ar.1.000) pour les formats 520mm x 720mm et 420mm x 620mm ;

cinq cent Ariary (Ar.500) pour les formats 320mm x 420mm et 210mm x 297mm.
