# Article 8

Exigences de l’emploi

Le processus de sélection doit être conçu pour couvrir une description détaillée de l'obligation d'emploi pertinente et doit mesurer tous les éléments pertinents impliqués tels que:

la fonction exercée;

les exigences de la tâche;

les compétences personnelles; et

l'environnement organisationnel dans lequel les tâches sont effectuées.
