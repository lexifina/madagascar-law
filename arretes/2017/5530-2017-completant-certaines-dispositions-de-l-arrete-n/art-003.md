# Article 3

Au sens du présent arrêté, on entend par « Agents Paramédicaux Diplômés d’Etat Fonctionnaires », les Infirmiers de l'Assistance Médicale, les Sages-femmes de l'Assistance Médicale, les Sages-femmes diplômées d'Etat, les Infirmiers diplômés d'Etat ainsi que les « Auxiliaires de Santé Fonctionnaires » composés des agents ci-après :

les agents Adjoints Techniques d’Hygiène et Assainissement ;

les Agents Adjoints de Santé publique ;

les Agents « Assistantes Sociales ».
