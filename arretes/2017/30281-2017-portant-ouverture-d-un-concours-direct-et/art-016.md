# Article 16

Le système de double correction des copies est obligatoire pour l’épreuve de Composition.

La troisième correction est requise dans le cas où l’écart des deux (02) notes initiales est de QUATRE (04) points pour les matières de base et de SEPT (07) points pour les autres matières. Dans ce cas, la note à considérer est la moyenne des deux (02) notes les plus proches.
