# Article 8

Communication

1. Outre les données de trafic communiquées par les transporteurs et les exploitants d’aérodrome, les formulaires demandés dans le cadre du programme statistique de l’OACI sont à communiquer à l’Autorité de l’aviation civile par les exploitants d’aérodrome, les exploitants d’aéronefs et, sauf convention contraire, les fournisseurs de service de navigation aérienne.
