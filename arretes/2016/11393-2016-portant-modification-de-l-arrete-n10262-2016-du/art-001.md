# Article premier

Les dispositions de l’article 14 de l’arrêté suscité sont modifiées comme suit :

Article 14 (nouveau) : Les modalités des épreuves sont définies ci-après :

A- Tests de présélection

Les tests de présélection consistent en une épreuve unique de deux heures qui se dérouleront le Lundi 22 Août 2016.

Ils sont présentés sous forme de questions à choix multiple, dirigées ou non.

Pour les deux types de concours, les questions porteront sur :

des tests psychotechniques,

des tests d’aptitude à la langue française,

des tests sur les programmes limitatifs prévus aux annexes I et II du présent arrêté.

Le barème de notation applicable aux tests de présélection est le suivant :

- bonne réponse : 1 point (un point)

- mauvaise réponse : 0 point (zéro point)

- pas de réponse : 0 point (zéro point)

- réponses multiple : 0 point (zéro point)

PHASE d’admission

La phase d’admission est reportée à des dates ultérieures. Elles seront communiquées au moins trois semaines avant les épreuves.

Les matières objet des épreuves restent inchangées.

Le reste sans changement
