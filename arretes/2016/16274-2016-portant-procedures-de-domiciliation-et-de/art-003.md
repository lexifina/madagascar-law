# Article 3

Le numéro de domiciliation est formé de 15 caractères selon la forme suivante :

Le code de la banque : 2 chiffres ;

Le code de l’agence : 5 chiffres ;

Les deux derniers chiffres du millésime de l’année ;

Le caractère E et ;

Un numéro d’ordre d’inscription de 5 chiffres pour chaque agence d’une banque commerçant au numéro 00001.
