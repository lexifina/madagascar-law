# Article 9

Un magasin d’optique doit respecter les normes suivantes :

Infrastructures :

Le magasin d’optique doit comporter trois salles :

une salle de vente mesurant au minimum 4m x 4m x 2,5m ;

une salle pour un atelier mesurant au minimum 3m x 3m x 2,5m ;

une salle de réfraction et de contactologie mesurant au minimum 3m x 3m x 2,5m.

b) Matériels :

divers tournevis et pinces ;

meuleuses de finition ;

1 meuleuse à main ;

1 lime à manche plastique ;

1 pic à coulisse ;

1 jeu de limes ;

1 roule goupille ;

2 diamants de monteur ;

1 enclumette acier poli ;

1 marteau horloger ;

1 taraud ;

1 sunbox (test UV Photochromique) ;

1 chauffrette ;

1 frontofocomètre manuel ;

1 frontofocomètre automatique ;

1 pupillomètrie ;

1 échelle d’acuité ;

1 Lensmeter ;

1 machine à percer ;

1 machine à silloner ;

1 machine à polissage ;

1 machine de centrage ;

des Cuves pour teinte ;

1 machine à tailler les verres.

Ressources humaines :

- un Opticien-Lunetier ;

- un vendeur ;

- un ouvrier monteur.
