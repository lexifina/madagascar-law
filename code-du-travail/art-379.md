# Article 379
Les Inspecteurs du travail et des lois sociales sont chargés, dans les conditions prévues à l'article 382 du présent Code, de constater, s'il y a lieu, les infractions :
1. au Code du travail ; 2. au Code de prévoyance sociale ; 3. aux dispositions pénales associées au Code du travail ; 4. aux règlementations sur l'immigration et l'émigration liées au travail.
