# Article 392
Les dispositions du présent Code du travail sont, de plein droit, applicables aux contrats individuels de travail en cours. Elles ne peuvent constituer une cause de rupture de ces contrats. Toute clause d'un contrat de travail en cours qui ne serait pas conforme aux dispositions du présent Code du travail ainsi qu'à celles des textes réglementaires pris en son application est considérée comme modifiée de plein droit par ces textes.
