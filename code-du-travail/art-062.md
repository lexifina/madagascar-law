# Article 62
Est considéré comme travailleur intérimaire, tout travailleur engagé pour remplacer provisoirement un titulaire à un poste pendant la durée d'absence de ce dernier n'excédant pas un (01) an.
Les conditions de l'intérim sont fixées d'accord parties sous réserve du respect des dispositions minimales du présent Code et, le cas échéant, de la convention collective.
