# Article 59

En application des dispositions de l’Article 88 alinéa 3 du Code Minier, dans les cas ci-dessous, la production d’un nouveau document environnemental est requise :

modification du programme de travail, impliquant l’utilisation de techniques ou de matériels nouveaux ;

modification du programme de travail, impliquant un changement de site non prévu dans le CCM initial ;

éventuellement, extension de substances impliquant l’un des cas ci-dessus.
