# Article 8

Les bénéficiaires de l’Education relative à l’Environnement sont :

les enseignants, les éducateurs, l es techniciens, les élèves, les étudiants, les enfants non scolarisés, les jeunes, les artistes, les sportifs, les journalistes, les adultes et en particulier les femmes, les citadins et les ruraux, les sociétés civile et militaire, les investisseurs et les opérateurs économiques, les élus et les décideurs, les analphabètes, les handicapés, les groupes défavorisés.
