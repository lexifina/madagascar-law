# Article 40

Les établissements d'hébergement comprennent:

- les hôtels

- les motels

- les relais

- les résidences de vacances

- les résidences de tourisme

- les villages de vacances

- les pensions de famille

- les écolodges

- les gîtes

- les chambres d'hôtes

- les auberges

- les terrains de camping
