# Article 7

Une base de données électronique, en langue anglaise, est tenue à jour au niveau de l'Administration Maritime sur les états et les renseignements concernant :

- les brevets;

- les certificats et

- les visas délivrés;

Elle doit être disponible et accessible pour les besoins d'authentification.

L'organisation et le fonctionnement de cette base de données sont définis par voie procédurale.
