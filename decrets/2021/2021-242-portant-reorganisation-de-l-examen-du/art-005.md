# Article 5

Les candidats à l’examen du Baccalauréat de l’Enseignement Général peuvent choisir au moment de leur inscription entre les séries avec les options suivantes:

Série Littéraire (L) : Option A1 ; Option A2 ; Option L;

Série Scientifique (S) : Option C ; Option D; Option S ;

Série OSE(Organisation- Société- Economie)

Ils ne peuvent s’inscrire qu’à une et une seule série par an.
