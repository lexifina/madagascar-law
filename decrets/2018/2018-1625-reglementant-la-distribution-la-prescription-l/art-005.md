# Article 5

Les méthodes contraceptives autorisées comportent :

les méthodes naturelles :

méthode de l’allaitement maternel et de l’aménorrhée (MAMA) ;

méthode des jours fixes (MJF) ;

méthode de la température basale ;

méthode sympto-thermique ;

méthode de la glaire cervicale ;

méthode du calendrier;

les méthodes barrières :

préservatifs masculins ;

préservatifs féminins ;

spermicides ;

diaphragme ;

cape cervical ;

les méthodes mécaniques :

dispositif intra-utérin (DIU) au cuivre ;

les méthodes hormonales ;

contraceptifs oraux combinés (COC);

contraceptifs oraux progestatifs (COP) ;

contraception d’urgence ;

contraceptifs injectables à progestatifs seuls (Intra Musculaire et Sous Cutanée) ;

contraceptifs injectables mensuels ou contraceptifs injectables combinés ;

patch combiné ;

anneau vaginal combiné ;

implants contraceptifs ;

dispositif intra-utérin (DIU) hormonal.

les contraceptions chirurgicales volontaires :

stérilisation masculine ou vasectomie ;

stérilisation féminine ou ligature des trompes.

Cette liste est exhaustive mais n’exclut pas les autres méthodes autorisées ultérieurement par l’Organisation Mondiale de la Santé.
