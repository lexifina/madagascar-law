# Article 16

Les édifices cultuels, les bâtiments des particuliers et les casernes ne peuvent être utilisés comme bureaux de vote.

Dans le cas où il ne se trouve pas dans le fokontany un bâtiment public pouvant abriter le bureau de vote, les responsables du Comité local de sécurité du Fokontany doivent en aviser le délégué administratif d'arrondissement dès la parution du décret convoquant les électeurs afin que ce dernier puisse demander une dérogation conformément aux dispositions de l'article 58 du Code électoral
