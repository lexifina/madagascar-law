# Article 5

Les demandes d'agrément doivent comporter les pièces ci-après :

Pour les groupements sportifs déjà constitués:

- le Statut

- le Règlement intérieur

- le Procès - verbal de la dernière Assemblée Générale

- le Bilan et le Compte d'exploitation de l'exercice précédent

- le Budget de l'exercice en cours

Pour les groupements sportifs nouvellement créés:

- le Statut

- le Règlement intérieur

- le Procès-verbal de l'Assemblée Générale

- le programme d'activités
