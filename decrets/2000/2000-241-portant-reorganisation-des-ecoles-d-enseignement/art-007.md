# Article 7

Le personnel de l'Ecole comprend :

LES AGENTS PERMANENTS :

- Le Directeur de l'Ecole,

- Le Chef de Filière,

- Le Conseiller Pédagogique,

- Le Gestionnaire,

- Le Personnel d'encadrement (Moniteurs - Monitrices),

- Le Personnel d'appui,

- Le Personnel d'exploitation,

LES AGENTS NON PERMANENTS :

Ils sont composés par le personnel enseignant dont les membres peuvent se constituer en Collège.

Leurs missions sont définies par le Règlement Intérieur de l'Ecole.
