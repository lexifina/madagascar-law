# Article premier

En application des jugements des Tribunaux Administratifs d’Antananarivo, de Fianarantsoa, de Toamasina et de Toliara susvisés, des élections partielles seront tenues dans les circonscriptions électorales de la :

- Commune rurale d’Antakavana dans le District d’Ankazobe;

- Commune rurale d’Alarobia dans le District de Manjakandriana;

- Commune rurale de Manakambahiny Est dans le District d’Ambatondrazaka;

- Commune rurale de Maroadabo dans le District d’Andilamena;

- Commune rurale de Tsaravinany dans le District d’Anosibe an’Ala;

- Commune urbaine de Moramanga dans le District de Moramanga;

- Commune urbaine de Fénérive-Est dans le District de Fénérive Est;

- Commune rurale d’Ampasimazava dans le District de Vavatenina;

- Commune rurale d’Anivorano Est dans le District de Brickaville;

- Commune rurale d’Ilaka Est dans le District de Vatomandry;

- Commune rurale d’Andohan’Ilakaka dans le District d’Ihosy;

- Commune rurale d’Andonabe dans le District de Mananjary;

- Commune rurale d’Andrananivo dans le District d’Ambovombe Androy;

- Commune rurale d’Ambahita dans le District de Bekily;

- Commune rurale de Kelivaho dans le District de Betroka;

- Commune rurale d’Andamasiny Vineta dans le District de Sakaraha;

- Commune rurale de Sakaraha dans le District de Sakaraha;

- Commune rurale d’Ankilivalo dans le District de Betioky Sud;

- Commune rurale d’Ambiky dans le District de Belo Tsiribihina.

Les électeurs dans lesdites circonscriptions électorales sont convoqués aux urnes le vendredi 13 novembre 2015, à partir de six heures à l’effet d’élire les Maires et les Conseillers communaux et municipaux.
