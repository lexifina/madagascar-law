# Article 7

Les dépenses imputables sur le compte de commerce " Sécurisation Maritime" sont décidées par le Ministre chargé des Forces Armées, dans le cadre d’un programme proposé par le Gestionnaire d’activités relatives à la sécurisation maritime.

Les opérations de dépenses sur ledit compte doivent respecter les dispositions du Code des Marchés Publics.
