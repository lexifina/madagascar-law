# Article 6

Site d’opération

Un chantier naval de construction ou de réparation maritime ou fluviale dispose d’un site d’opération approprié. Ledit site est équipé d’infrastructures appropriées.

Ce site est pourvu d’au moins des infrastructures citées ci-après :

Bassin ;

Bureaux ;

Slipway&Cabestan ;

Magasin ;

Hangar ;

Toilette ;

Source d’eau douce

Vestiaire ;

Source d’électricité ;

Atelier ;

Radoub ou Dock flottant ou Cale sèche
