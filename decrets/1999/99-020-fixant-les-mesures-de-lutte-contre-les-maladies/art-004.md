# Article 4

Le personnel qualifié pour la question sanitaire apicole est placé sous l’autorité du Directeur des Services Vétérinaires, et comprend notamment :

- Les Vétérinaires

- Les spécialistes de l’Elevage apicole qui sont:

- Les Ingénieurs d’Elevage

- Les Adjoints techniques d’Elevage

- Les Assistants d’Elevage

- Les Employés Techniques d’Elevage

- Les Aides-spécialistes apicoles et,

- Les Techniciens Traditionnels agréés
