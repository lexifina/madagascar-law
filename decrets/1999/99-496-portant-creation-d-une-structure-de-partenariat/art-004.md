# Article 4

Le "Partenariat pour le Développement de l'Ecole Primaire Publique " est composé de toute personne physique ou morale intéressée par 1e Développement de l'Ecole :

- les parents d'élèves

- les habitants de 1a localité où se trouve l'Ecole ;

- les associations de bienfaisance laïques et /ou religieuses ;

- les opérateurs économiques locaux, régionaux ou nationaux ;

- les représentants des Collectivités Territoriales Décentralisées (CTD) ;

- les Organisations Non Gouvernementales ;

- les personnels de l'école ;

Ces entités constituent de plein droit l'Assemblée Générale stipulée par l'article 5 ci-dessous.
