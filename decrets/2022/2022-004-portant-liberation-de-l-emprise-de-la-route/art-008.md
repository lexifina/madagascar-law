# Article 8

Le Fonds pour la Réinstallation Involontaire (FRI) est alimenté par des ressources provenant des Ressources Propres Internes (RPI) de l’Etat. Le Fonds correspondant est déjà disponible dans le compte de dépôt de l’Agence Routière, sur la ligne d’imputation budgétaire ci-après :

 Mission : 610  Catégorie : 3 (catégorie des dépenses)  Programme : 206  Activité projet : 237 (ceci est inclus dans l’activité 000 dans le budget de l’AR)  SOA : 90-62-1-000-01164  Compte 6563 : Indemnisations  Code AR : 10-001-001-A RPI  Financement : 10-001-001-A RPI  Section convention du projet : 237 - travaux de Réhabilitation de la Route Nationale Secondaire n°43 (RNS43) reliant « Faratsiho - Sambaina ; Ambohibary - Ampetsapetsa »,
