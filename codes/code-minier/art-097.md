# Article 97

Pour la transformation du PR en PREA, les documents suivants sont requis :

1. le formulaire de demande à déposer avant l’expiration de la durée de validité dudit Permis minier ;

2. les documents relatant l’état d’avancement des travaux de recherche déjà effectués ;

3. le rapport technique de recherche ;

4. le rapport périodique d’activités.
