# Article 151

Dans le cadre du contrôle des registres, laissez-passer et documents annexes tenus par les titulaires doivent communiquer à la première, réquisition des Administrations fiscale et/ ou douanière sous peine d'une inculpation pour refus d'exercice ou d'opposition aux fonctions prévues par le Code Général des impôts et le Code des Douanes.
