# Article 83

Les comptoirs agréés par l'Agence de l'Or, qui sont des sociétés privées de droit malagasy spécialisées dans le commerce de l'or, peuvent acheter l'or auprès des titulaires de permis minière exploitant ce métal ainsi qu'auprès des Collecteurs agréés à l'intérieur du Territoire National.

Les critères requis pour l'octroi de cet agrément du comptoir, sont précisés dans le décret d'application du présent Code .
