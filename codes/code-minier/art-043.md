# Article 43

Toute demande de permis minier est rédigée sur un formulaire à retirer auprès du bureau du Cadastre minier, dont le modèle est fixé dans le décret d'application du présent Code.

Après avoir rempli correctement le formulaire, le requérant dépose la demande auprès dudit bureau récépissé indiquant les jours heure et minute du dépôt qui font foi.
