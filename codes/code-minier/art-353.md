# Article 353

Le défaut de communication, pour tout Permis minier, des rapports périodiques obligatoires dans le délai réglementaire, fait l'objet d'une lettre de rappel, dans laquelle est énoncée l'obligation de communiquer les documents dans un délai de deux (2) mois.

Jusqu’à la régularisation, le titulaire de Permis minier n’est pas autorisé à émettre de laissez –passer.
