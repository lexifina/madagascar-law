# Article 187

Toute Infraction au présent Code ainsi qu'à ses textes d'application est constatée par un procès-verbal rédigé en une seule expédition. Il en est fait copie pour le nombre d'exemplaires jugés nécessaires. Ces copies sont certifiées conformes par les agents verbalisateurs.

Conformément à l'article 132 du Code de Procédure pénale, l'original du procès-verbal est envoyé d'office au Procureur du Tribunal compétent.
