# Article 427

Les Autorisations de carrière valides, octroyées par la Commune avant la date d’entrée en vigueur du présent Code gardent leur validité jusqu’à leur échéance.

A l’arrivée de ladite échéance, le titulaire de l’Autorisation est tenu de se conformer aux nouvelles dispositions, suivant les classifications des carrières, prévues par le présent Code.
