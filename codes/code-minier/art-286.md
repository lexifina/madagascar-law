# Article 286

Les Droits et taxes spéciaux sur les produits miniers sont payables par :

les titulaires du Permis minier pour les produits issus des périmètres miniers ;

les comptoirs de l’or, les collecteurs, pour les produits issus des exploitations artisanales de l’or ;

les Groupements ;

les acheteurs revendeurs de produits miniers.
