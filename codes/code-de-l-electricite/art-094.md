# Article 94

Pour les ventes des Permissionnaires, les prix sont règlementés selon les modalités de l’article 81. Cependant, dans le cas d'électrifications financées totalement ou partiellement par des subventions d'équipement, pour lesquelles un tarif serait éventuellement établi dans l'accord de subvention, l'Autorité de Régulation de l’Electricité veille à l'application du tarif fixé.
