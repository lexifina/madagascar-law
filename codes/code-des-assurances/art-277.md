# Article 277

Entrée en vigueur du Code des Assurances

Le présent Code des Assurances entre en vigueur dès sa publication au Journal Officie1.

Les entreprises d'assurance agréées avant l'entrée en vigueur du présent Code conservent leurs agréments. Néanmoins, elles disposent d'un délai de deux ans pour s'adapter aux dispositions du présent Code.

Les agents d'assurance nommés avant l'entrée en vigueur du Code disposent d'un délai de deux ans à partir de sa publication pour se mettre en règle avec les dispositions du Livre IV. .

Des textes réglementaires seront pris pour l'application de ce présent Code.
