# Article 143

Le présent Code Electoral abroge:

l’ordonnance modifiée N° 92-041 du 02 Octobre 1992 portant Code Electoral;

l’article 2 de l’ordonnance modifiée N° 60-082 du 13 Août 1960 relative aux réunions publiques et aux manifestations sur la voie publique;

les articles 109 à 113 du Code pénal.
