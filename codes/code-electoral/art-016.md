# Article 16

L’accomplissement des formalités prescrites à l’article précédent est constaté par un procès-verbal établi par la commission.

Le Préfet de Police pour la Commune Urbaine d’Antananarivo, le Chef de District pour les autres communes urbaines ou le Chef d’arrondissement administratif pour les communes rurales selon le cas, en reçoit une copie.
