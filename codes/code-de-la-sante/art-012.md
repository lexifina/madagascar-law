# Article 12

L’organisation des soins dans le secteur public s’articule sur quatre niveaux :

les formations sanitaires de base pour les premiers contacts : les Centres de Santé de Base niveau 1 et niveau 2 (CSB1 et CSB2) ;

les Centres Hospitaliers de Référence de District (CHRD) ;

les Centres Hospitaliers de Référence Régionale (CHRR) ;

les Centres Hospitaliers Universitaires (CHU).

Le premier niveau de la pyramide sanitaire comprend les CSB1, les CSB2. Ils assurent l’offre des soins curatifs, préventifs et promotionnels de bases.
