# Article 12

Il est établi tous les cinq ans un relevé des tables annuelles. Ces relevés qui portent le nom de «tables quinquennales» sont dressés par l'Officier d’état civil dans les mêmes formes que les tables annuelles et comportent les mêmes mentions. Les tables quinquennales sont établies en trois exemplaires, dont l'un est joint aux registres conservés au centre d'état civil, l'autre déposé au greffe du Tribunal de première instance et le troisième aux archives du Ministère de la Justice.

Les tables quinquennales sont établies dans l'ordre alphabétique par année, par catégorie d'actes et séparément pour les naissances, pour les mariages, pour les décès, pour les adoptions, pour les rejets, pour les changements de nom et pour les reconnaissances.

Les tables quinquennales sont également établies en version numérique.
