# Article 718

Les fonctions du commissaire aux comptes expirent à l'issue de l'assemblée générale qui statue soit sur les comptes du premier exercice lorsqu'il est désigné dans les statuts, soit sur les comptes du troisième exercice lorsqu'il est désigné par l'assemblée générale constitutive, soit sur les comptes du sixième exercice lorsqu'il est nommé par l'assemblée générale ordinaire.
