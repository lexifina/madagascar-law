# Article 124

La CSBF mandate l’Administrateur de résolution à mettre en œuvre notamment les opérations ci-après :

sur l’institution

la cession de toute ou partie de l’institution ;

la fusion-acquisition ;

la création d’une nouvelle institution qui reprend les actifs sains ;

le traitement des actifs non vendus ;

toutes mesures nécessaires pour éponger les pertes ;

sur les actionnaires

la transformation ou la consolidation des créances en actions ;

la concession pour favoriser la vente de l’institution ;

la recapitalisation ;

sur la gouvernance

le déclenchement des poursuites judiciaires contre toute personne impliquée dans les fraudes ou malversations ;

sur les créanciers

l’abandon de toute ou partie des créances ;

l’appui financier des partenaires techniques et financiers ;

la concession pour favoriser la vente de l’institution.

Toute autre transaction ou opération qui contribue à la résolution de l’institution fragile.
