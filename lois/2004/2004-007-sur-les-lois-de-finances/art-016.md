# Article 16

Dépenses courantes structurelles

Les dépenses courantes structurelles sont les dépenses limitées dans le temps, destinées à la réalisation d'objectifs majeurs de redressement ou d'ajustement structurel.

Les dépenses courantes structurelles comprennent :

- les dépenses d'intervention sociales;

- les dépenses d'intervention économiques;

- les dépenses diverses et imprévues;

- les autres dépenses d'intervention.
