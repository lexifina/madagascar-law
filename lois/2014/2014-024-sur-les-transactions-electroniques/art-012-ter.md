# Article 12 ter

1. Lorsque l’expéditeur reçoit l’accusé de réception, le message de données en question est réputé avoir été reçu par le destinataire. Cette présomption n’implique pas que la communication électronique corresponde au message reçu.

2. Lorsque l’accusé de réception indique que le message de données en question est conforme aux conditions techniques soit convenues, soit fixées dans les normes applicables, ces conditions sont présumées remplies.
